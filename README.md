# flowd

A local only terminal day planner. Plan the day in time blocks, track each block with single keys,
and review the day in one glance.

- One binary, fully offline, data stays on the machine.
- Keyboard only. No team, no sync, no pings while closed.

Docs live in `docs/`:

- `00-vision.md` why it exists
- `01-requirements.md` what it must do and how well
- `02-domain.md` blocks, days and house rules
- `03-architecture.md` wiring, saves and failures
